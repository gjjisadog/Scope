# Capture 历史与录波事件

Live 触发完成后，每个 Capture 都按到达顺序加入事件历史。同一个 SCP1 SampleBatch 中完成的多个触发不会只保留第一个。

## 容量策略

- 默认最多 100 条。
- 默认最多 128 MiB 内存 Capture 数据。
- 超限时从最旧的未固定项开始淘汰。
- 固定项不会自动淘汰；若固定项占满预算，新 Capture 会明确提示无法保留，但采集和已启动的录波继续运行。

事件保存触发样点、时间、模式、边沿、电平、前后置长度、Auto 超时、完整性、标签、备注和固定状态。“保持当前选择”启用后，新事件不会抢占当前查看项。

清除包含固定项的历史需要二次确认。重新 Arm 只清除触发器内部工作状态，不清除事件历史。

## `.scope` 与工程

普通 `.scope` V1 中的多个 TriggerRecord 会显示为可导航事件，选择事件后光标和视图定位到对应前后置窗口。录波格式没有变化。

保存 `.scopeproj` 时，已有录波事件保持源文件引用；仅存在于内存的 Capture 会物化为伴随 `.scope` V1 资产。资产可由普通 `.scope` 读取器独立打开和验证。
