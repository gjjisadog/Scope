# 工程测量定义

Scope Analyzer 0.11.0 对离线光标区间、冻结 Capture 和 Live 窗口使用同一测量引擎。

## 标量

- Average：有效有限样点的算术平均值。
- RMS：包含直流分量的真 RMS，即 `sqrt(mean(x²))`。
- `+Peak` / `-Peak`：最大值和最小值；`Abs` 为两者绝对值的较大者。
- `Pk-Pk`：最大值减最小值。
- Frequency：带自适应回差的上升过零周期估计。周期先取中位数，再剔除偏离中位数超过 20% 的异常值。

频率至少需要 3 个有效周期。数据 gap 两侧不会连成一个周期；低幅值、时间戳无效或样点不足时显示无效质量，而不是回退为光标 `1/dX`。

## 三相功率

用户绑定 `Va/Vb/Vc` 和 `Ia/Ib/Ic` 六个互不重复的模拟通道：

- `P = mean(Va·Ia + Vb·Ib + Vc·Ic)`，包含谐波贡献。
- `Q₁`：以测得/标称基波频率计算的基波复功率虚部。
- `S = sqrt(mean(Va²+Vb²+Vc²)) × sqrt(mean(Ia²+Ib²+Ic²))`。
- `PF = P/S`；当 `S` 接近零时无效。

正 Q 表示在当前电压/电流极性和相序约定下的感性方向；反接电流或改变相序会改变符号。V/kV 与 A/kA 会生成对应的 W/kW/MW、var/kvar/Mvar 和 VA/kVA/MVA 标签。未知单位仍计算工程数值，但应结合质量提示解释。

Live 默认最多使用最新 131,072 个全分辨率样点，计算在后台任务中执行；通道表、倍率或功率绑定改变后，旧任务结果不会覆盖新配置。
